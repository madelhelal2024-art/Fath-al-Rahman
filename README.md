# فتح الرحمن التفاعلي

نسخة أولية قابلة للتوسع من منصة **فتح الرحمن** التعليمية. تعمل بواجهة عربية من اليمين إلى اليسار، وباستخدام HTML وCSS وJavaScript دون الحاجة إلى بيئة بناء.

## المحتوى الموجود

| الدرس | صفحة الكتاب | ملف الصوت | الحالة |
|---|---|---|---|
| الحروف الهجائية | `assets/pages/01-letters.webp` | `assets/audio/01-letters.m4a` | مرفق |
| الحروف بالفتحة | `assets/pages/02-fatha.webp` | `assets/audio/02-fatha.m4a` | مرفق |
| كلمات بالفتحة، تدريب ١ | `assets/pages/03-words-1.webp` | `assets/audio/03-words-1.m4a` | مرفق |
| كلمات بالفتحة، تدريب ٢ | `assets/pages/04-words-2.webp` | `assets/audio/04-words-2.m4a` | مرفق |

**تأكيد ربط الصوتيات:** أكد صاحب المحتوى يوم ٢٥ أكتوبر ٢٠٢٦ أن التسجيلات الأربع مرتبة بنفس ترتيب الصور الأربع. هذا تأكيد لمطابقة الملف للصفحة، ولا يعني بعدُ وجود توقيت مستقل لكل حرف أو كلمة. ملفات الصوت أعيد تغليفها من AAC إلى M4A دون إعادة ترميز أو فقد جودة؛ الصور الأصلية حُوّلت إلى WebP لتسريع التحميل.

## الوظائف

- قارئ يعرض صور الصفحات الأصلية دون إعادة كتابة النص القرآني أو تغيير ضبطه.
- تكبير صفحات الكتاب والتنقل بينها.
- تسجيل كامل لكل صفحة مع تغيير سرعة التشغيل، وتشغيل مقطع حرف أو كلمة عند الضغط على العنصر الموجود في صورة الصفحة.
- ثلاثة أسئلة اختيار من متعدد لكل صفحة، مع إمكانية تصحيح الخطأ وإعادة المحاولة، ونشاط لتوصيل الحرف باسمه في الدرس الأول.
- حفظ إكمال الصفحات محليًا في متصفح الجهاز، دون حسابات أو جمع بيانات.
- تصميم متجاوب للكمبيوتر والتابلت والجوال، وهوية مؤقتة مستقلة عن شعار الأبرار الموجود في نموذج البوربوينت.

## التشغيل محليًا

من داخل هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

يمكن استضافة هذه النسخة على أي خادم ملفات ثابتة، بما في ذلك GitHub Pages بعد تفعيله يدويًا. لا تنشر الحسابات أو بيانات الطلاب في هذه النسخة؛ ليس لديها خادم أو نظام دخول.

## تقطيع الصوتيات إلى مقاطع مستقلة

يحتوي ملف `audio-segments.js` على مواقيت ١٠٩ مقاطع: ٢٩ للحروف، و٢٨ للفتحة، و٢٨ لكلمات التدريب الأول، و٢٤ لكلمات التدريب الثاني. تستخدم المنصة هذه المواقيت للتشغيل الفردي دون تحميل نسخ متعددة من الصوت. كما يحتوي الملف `assets/audio/individual-clips.zip` على تسجيل مستقل لكل مقطع مع فهرس CSV.

يمكن إعادة تصدير الملفات المقطّعة باستخدام FFmpeg:

```bash
node scripts/split-audio.mjs
```

**ضبط الجودة:** هذا تقسيم آلي مبني على فترات الصمت ويحتاج الاستماع إلى كل مقطع للتأكد من مطابقته. يوجد في صفحة الحروف ٣٠ عنصرًا بصريًا مقابل ٢٩ مقطعًا صوتيًا واضحًا؛ لذلك تظل القراءة الفردية للعنصر الأخير غير مفعّلة بانتظار التدقيق أو تسجيل إضافي. تسجيل الصفحة الكامل ما زال متاحًا.

## الخطوات القادمة

1. إجراء مراجعة تعليمية نهائية لدقة القراءة والنصوص قبل الإطلاق العام.
2. مراجعة جميع المقاطع المئة والتسعة سمعيًا، واستكمال الصوت الناقص أو تصحيح أية محاذاة غير مطابقة.
3. تحويل المحتوى إلى بيانات منظّمة تسمح بتوسيع الدروس والأسئلة دون تعديل واجهة المستخدم.
4. تحديد صلاحيات الطالب والمعلم والمشرف وولي الأمر قبل تصميم تخزين الحسابات والتقدم على الخادم.

## مصدر المحتوى

صور الصفحات والصوتيات من الملفات التي زوّد بها صاحب المشروع، ونموذج التفاعل مستوحى من ملف البوربوينت المرفق. الاستخدام والنشر مسؤولية مالك المحتوى.
